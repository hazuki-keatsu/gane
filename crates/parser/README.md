This crate is ported from `go/parser`, version 1.27.0, which provides the capability to transform source code into abstract syntax tree. 

This crate contains Rust adaptations of components from the Go standard library, including parts of `go/parser`, `go/scanner`, `go/token`, and `go/ast`.
